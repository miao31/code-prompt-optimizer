示例 1 排序函数（生成类）

「帮我写一个函数，把数组排序」

原始请求过于模糊，skill 先补全以下隐藏假设，再生成双版本提示词：

语言 未指定 顺序 升/降未定 稳定性 是否稳定 原地 改原数组 or 新数组 边界 空值/重复 性能 有无要求 
你是一名资深 JavaScript 工程师。请用 JavaScript 实现稳定升序排序函数 sortStable(arr)：不修改原数组、返回新数组；空数组返回 []；元素为同类型数字或字符串；时间复杂度 O(n log n)；附 2 个使用示例与边界测试。
# 角色
资深 JavaScript 工程师，熟悉稳定排序与不变性（immutability）。

# 任务
实现 sortStable(arr)，对输入数组做稳定升序排序。

# 约束
- 不修改原数组，返回新数组（纯函数）
- 仅处理同类型元素：数字或字符串
- 时间复杂度 O(n log n)，空间合理
- 空数组返回 []，重复元素保持原有相对顺序

# 输入 / 输出
输入：arr: (number|string)[]   输出：排序后的新数组

# 交付
1) 函数实现  2) 2 个使用示例  3) 边界测试用例（空数组、全等重复、混合类型报错）

# 验收
运行示例与测试无报错；原数组未被改动。

示例 2 报错排查（调试类）

「我的代码报错，帮我看看」

调试类请求最缺上下文，skill 强制补全 5 项关键信息后再输出：

栈信息 报错原文 复现代码 最小片段 期望 应得结果 环境 语言/版本 已试 排查动作 
下面是 Python 3.11 报错（附完整 traceback）。请先给出最可能的根因（1 句），再给最小修改补丁，最后说明为什么这样改。不要重写整个文件。我已试过重启和 pip install -U，无效。期望：函数返回去重后的列表。
# 背景
Python 3.11 脚本，运行时抛异常（traceback 见下）。

# 提供的信息
- 完整报错 traceback（粘贴）
- 能复现的最小代码片段（粘贴）
- 期望行为：函数返回去重后的列表
- 已尝试：重启解释器、pip install -U，均无效

# 你的任务
1) 用 1 句话指出最可能的根因
2) 给出最小修改补丁（diff 形式）
3) 解释为什么这样改、是否引入副作用

# 约束
- 不要重写整个文件
- 不引入新依赖
- 保持原接口签名不变

# 验收
补丁应用后脚本不再报错，且输出为去重列表。
